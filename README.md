# Predictive Maintenance & Failure Early-Warning System Using Machine Learning

## Project Overview
This project uses machine learning to analyze machine operating conditions and predict recorded machine failures using the AI4I 2020 Predictive Maintenance Dataset.

## Problem Statements
1. Machine Failure Prediction
2. Analysis of Machine Operating Conditions
3. Machine Operating Condition Grouping
4. Comparison of Machine Failure Prediction Models
5. Neural Network-Based Machine Failure Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)
- Multiple Linear Regression
- K-Means Clustering
- Hierarchical Clustering
- Random Forest
- Bagging and AdaBoost
- Multi-Layer Perceptron (MLP)
- Principal Component Analysis (PCA)

## Project Files
- `predictive_maintenance.py` — main project code
- `ai4i2020.csv` — dataset
- `machine_failure_model_comparison.csv` — model evaluation results

## Installation
Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

## How to Run
Keep the Python file and dataset in the same folder, then run:

```bash
python predictive_maintenance.py
```

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## Project Status
Academic machine learning project. Model performance should be interpreted using the results generated by the program.
